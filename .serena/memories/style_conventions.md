# Style & Conventions

- Language: TypeScript + React (Next.js App Router).
- Indentation: 2 spaces.
- Prettier: single quotes, semicolons, printWidth 100, Tailwind plugin enabled (`.prettierrc.js`).
- ESLint: Next.js recommended + core-web-vitals, TypeScript recommended, simple-import-sort enforced (`eslint.config.js`).
- Naming: follow existing conventions; `kebab-case` for folders, `PascalCase` for components.
- Prefer `yarn` scripts over npm.
